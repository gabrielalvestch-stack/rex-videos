# Rex: arquivo de vídeos

Vídeos finais dos canais **Rex Explica** (PT) e **Rex Explains** (EN).

Cada vídeo fica numa *release* (`video-NN`), com os arquivos PT e EN como anexos.
Os links diretos dos anexos são usados pelo Buffer e pelo Metricool para publicar no YouTube e no TikTok.

- Release `video-NN`: `rex_NN_<tema>.mp4` (PT) e `rex_NN_<theme>_EN.mp4` (EN)
- Os arquivos ficam guardados para montar os compilados longos do YouTube.
- Nada de código aqui: só os vídeos e esta explicação.
